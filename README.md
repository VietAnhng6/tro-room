# AuditLog-System

Ứng dụng demo "Nhật ký hoạt động hệ thống" dùng HTML, CSS và JavaScript thuần.

## Chạy nhanh

Mở Terminal trong thư mục dự án và chạy:

```bash
npx serve .
```

Sau đó mở:

http://localhost:3000

Nếu `npx serve .` hỏi cài package, chọn `y`.

Dữ liệu demo được lưu bằng localStorage của trình duyệt.
